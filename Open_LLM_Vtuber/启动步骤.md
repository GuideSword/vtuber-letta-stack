以下是启动Open LLM Vtuber系统的完整步骤：

## 1. 启动Letta服务器（必要）
- 打开PowerShell终端
- 导航到Letta目录： cd "D:\ChatWithSmallC\Letta"
- 激活虚拟环境： .\venv\Scripts\Activate.ps1
- 启动Letta服务器： letta server --port 9000
- 验证Letta服务器状态：访问 http://localhost:9000 应该能看到Letta的API文档
## 2. 启动Open LLM Vtuber服务器（必要）
- 打开另一个PowerShell终端
- 导航到Open LLM Vtuber目录： cd "D:\ChatWithSmallC\Open_LLM_Vtuber"
- 激活虚拟环境（如果有）： .\.venv\Scripts\Activate.ps1
- 启动服务器： python run_server.py
- 验证服务器状态：访问 http://localhost:12393 应该能看到Open LLM Vtuber的Web界面
## 3. 测试与AI对话
- 在浏览器中打开 http://localhost:12393
- 在输入框中输入消息，例如："你好"
- 查看AI的回复，确认它能够正常回应
## 注意事项
- 确保所有服务都使用正确的端口：
  - Letta: 9000
  - Open LLM Vtuber: 12393
- 当前 Open LLM Vtuber 使用 Letta Agent；实际大模型由 Letta 中的 agent 配置决定。
- 只有当 Letta 里的 agent 使用 Ollama 作为后端时，才需要额外启动 Ollama。
- 如果遇到端口冲突，可以使用 netstat -ano | findstr :端口号 查看占用端口的进程，然后使用 taskkill /PID 进程ID /F 终止该进程
- 如果AI回复异常，可以检查Letta服务器的日志，查看是否有错误信息
